# Sommie Leonard

I build automations that take repetitive, manual work off business owners' plates, so they can actually run their business instead of babysitting spreadsheets, follow ups, and admin. Brand identity design is the second thing I do, and I do that well too, but automation is where I live.

This repo holds real systems I've built. Not demos, not tutorials followed step by step, actual automations solving actual problems for actual situations.

What's in here

Invoice Payment Monitoring System
Every business that sends invoices has the same annoying problem: someone has to remember who hasn't paid, keep checking manually, and follow up themselves when a client goes quiet. This system creates the invoice, sends it, then checks on its own whether it's been paid. If someone's overdue, it sends them a personal reminder automatically, but never more than once a day, so nobody gets hounded. The business owner does nothing after the invoice goes out. See it here →

AI Business Expense Assistant
Bookkeeping eats hours that could go toward actual work. This system takes in expense submissions, uses AI to figure out what category each one belongs to, automatically routes anything that needs approval to the right person, and puts together a full financial summary on its own. What used to be manual sorting and spreadsheet wrangling now runs itself. See it here →

Storytelling Challenge Entry System
When a competition gets hundreds of entries, reading and scoring each one by hand isn't realistic. This system reads every entry, checks it against a set of rules, and automatically sorts it into approved, rejected, or needs a second look, work that would've taken hours, done instantly and consistently. See it here →
